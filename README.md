# DXN Orion — Production Setup & Deployment Guide

Production-ready, full-stack pre-launch website and CRM platform for **DXN Orion** (Sector 22D, Yamuna Expressway, Greater Noida).

---

## 🏗 System Architecture & Technology Stack

- **Frontend & App Engine:** React 19 + TypeScript + Tailwind CSS (v4) with custom luxury tokens (`#0B1426` Midnight Navy, `#C9A86A` Champagne Gold, `#F7F4EE` Ivory).
- **Backend API:** Node.js Express server (`server.ts`) supporting Vite middleware in development and serving static bundles in production.
- **Database:** Google Cloud SQL (PostgreSQL 15) managed via Prisma ORM schema (`prisma/schema.prisma`).
- **Object Storage:** Google Cloud Storage for blog and floor plan media with WebP conversion.
- **Deployment Platform:** Google Cloud Run (Serverless containerized via `Dockerfile` and `cloudbuild.yaml`).
- **Secrets Management:** Google Secret Manager.

---

## 🚀 Step-by-Step Cloud Deployment

### 1. Create Google Cloud SQL (PostgreSQL 15) Instance
```bash
# Enable required APIs
gcloud services enable sqladmin.googleapis.com run.googleapis.com secretmanager.googleapis.com storage.googleapis.com

# Create PostgreSQL 15 instance in Mumbai (asia-south1)
gcloud sql instances create dxn-orion-pg15 \
    --database-version=POSTGRES_15 \
    --tier=db-custom-2-7680 \
    --region=asia-south1 \
    --availability-type=REGIONAL \
    --storage-size=20GB \
    --storage-auto-increase \
    --backup-start-time=22:00

# Create application database
gcloud sql databases create dxn_orion_db --instance=dxn-orion-pg15

# Create database user
gcloud sql users create dxn_db_user \
    --instance=dxn-orion-pg15 \
    --password="YOUR_STRONG_SQL_PASSWORD"
```

Get the instance connection name:
```bash
gcloud sql instances describe dxn-orion-pg15 --format='value(connectionName)'
# Example output: your-project-id:asia-south1:dxn-orion-pg15
```

---

### 2. Create Google Cloud Storage Bucket for Media
```bash
# Create public read bucket for media
gsutil mb -p your-project-id -c STANDARD -l asia-south1 gs://dxn-orion-media-public/

# Allow public read on uploaded images
gsutil iam ch allUsers:objectViewer gs://dxn-orion-media-public

# Configure CORS
cat <<EOF > cors.json
[
  {
    "origin": ["https://dxn-orion.com", "http://localhost:3000"],
    "responseHeader": ["Content-Type"],
    "method": ["GET", "PUT", "POST"],
    "maxAgeSeconds": 3600
  }
]
EOF
gsutil cors set cors.json gs://dxn-orion-media-public
```

---

### 3. Configure Google Secret Manager
```bash
# Admin credentials (seeded on first run)
echo -n "shivam@dxn-orion.com" | gcloud secrets create dxn-admin-email --data-file=-
echo -n "YourSecureAdminPass!2026" | gcloud secrets create dxn-admin-password --data-file=-

# Database credentials
echo -n "YOUR_STRONG_SQL_PASSWORD" | gcloud secrets create dxn-db-pass --data-file=-

# Session JWT secret
echo -n "$(openssl rand -base64 32)" | gcloud secrets create dxn-jwt-secret --data-file=-
```

---

### 4. Deploy to Google Cloud Run
```bash
# Submit build via Cloud Build
gcloud builds submit --config=cloudbuild.yaml \
    --substitutions=_INSTANCE_CONNECTION_NAME="your-project-id:asia-south1:dxn-orion-pg15"
```

---

### 5. Map Custom Domain (`dxn-orion.com`)
```bash
# Verify ownership of your domain in Cloud Console:
# Navigate to: Cloud Run > Manage Custom Domains > Add Mapping
gcloud beta run domain-mappings create \
    --service=dxn-orion-service \
    --domain=dxn-orion.com \
    --region=asia-south1

# Map www subdomain:
gcloud beta run domain-mappings create \
    --service=dxn-orion-service \
    --domain=www.dxn-orion.com \
    --region=asia-south1
```
Follow the DNS instructions generated by Google Cloud Run to update your Registrar DNS records (A and AAAA records, or CNAME for www). Google Cloud automatically provisions and renews SSL/TLS certificates.

---

### 6. Google Search Console & Sitemap Submission
1. Open [Google Search Console](https://search.google.com/search-console).
2. Add Property: `https://dxn-orion.com`.
3. Verify ownership via HTML meta tag (configured in Admin Panel > Settings > Search Console verification code).
4. In the **Sitemaps** section, submit:
   ```
   https://dxn-orion.com/sitemap.xml
   ```
5. All dynamic blog posts, floor plans, and amenities pages will be automatically crawled and indexed.
